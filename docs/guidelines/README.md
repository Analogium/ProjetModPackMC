# Vision du projet

Le but du projet est de concevoir une expérience **ARPG (jeu de rôle d'action)**
dans Minecraft, associant des **mécaniques de gestion** et de **hack and slash**.

Ces trois axes guident la conception du gameplay :

- **ARPG** : une expérience de jeu de rôle centrée sur l'action.
- **Gestion** : des mécaniques de gestion intégrées à cette expérience.
- **Hack and slash** : des combats orientés vers l'action et les affrontements
  avec les ennemis.

Les systèmes précis, leur articulation, le public visé et les priorités de
développement restent à définir. Cette vision ne constitue pas une liste de
fonctionnalités déjà décidées ou implémentées.

Le dépôt contient actuellement un seul mod NeoForge, `moddevarpg`, qui porte
cette ambition. Le périmètre technique et les règles de validation sont définis
dans [init.md](../../init.md).
